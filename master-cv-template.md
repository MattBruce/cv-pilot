# Master CV

This is the single source of truth for your career information. It is deliberately more detailed than an application CV. Keep useful facts here even if they would not all appear in a finished document.

## How to use this file

- **Completeness over polish:** Add information in your own words. Rough notes are fine; factual completeness matters more than finished prose.
- **Ground truth:** Keep facts accurate and specific. Never let an AI invent dates, metrics, responsibilities, or tools.
- **Achievements > Responsibilities:** Separate what you accomplished from routine daily duties wherever possible.
- **Context matters:** Include scale, constraints, your personal contribution, and measurable outcomes.
- **Dates & numbers:** Use `YYYY-MM` for dates (`present` for current role). Mark estimates clearly (e.g. `~£500k`, `approx. 20 users`).
- **Generation:** For each job application, provide this file and the job description. The AI will select, prioritise, and format relevant evidence.

# System Prompt: Instructions for Generating Application Documents

When using this master record to prepare a tailored CV or cover letter:

1. **Role Analysis:** Analyze the target job description to identify essential requirements, desirable criteria, tech stack, and key company objectives.
2. **Strict Ground Truth (No Hallucination):** Use *only* facts, roles, tools, and outcomes present in this master record. Never invent or embellish technologies, dates, metrics, or achievements.
3. **Strategic Selection:** Do not dump every detail. Select and prioritize the most compelling, relevant evidence for the specific role.
4. **Impact-First Bullet Points:** Frame experience using the format: *Action verb + Context + Measurable Outcome / Impact*.
5. **Match Terminology Honestly:** Align terminology with the job description where accurate (e.g. if the JD asks for "CI/CD pipelines" and this CV lists "automated GitHub Actions deployment", use the phrasing familiar to the recruiter/ATS without lying).
6. **Format & ATS Standards:** Output clean, single-column Markdown or clean plain text. Avoid multi-column layouts, tables, text boxes, or icons.
7. **Flag Missing Requirements:** If the job description requires a key skill that is absent from this master record, highlight it to the user in a short gap-analysis summary rather than inventing it.
8. **Verification Checklist:** Always conclude by listing any claims, numbers, or assumptions made in the draft that the user should verify before submitting.
